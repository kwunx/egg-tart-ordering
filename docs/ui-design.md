# 微信小程序点餐系统 - UI/UX 设计

## 1. 设计目标

- 简单
- 清晰
- 商品优先
- 操作路径短
- 套餐选择规则明确
- 购物车和订单金额明确
- 状态反馈明确
- 能直接映射到原生微信小程序实现

---

## 4. 关键交互

前端可以提前展示库存状态，但最终库存必须以后端结果为准。

例如：

```text
用户点击提交
↓
后端返回库存不足
↓
前端显示“库存不足，请重新选择”
```

不能因为前端显示“有库存”就认为下单一定成功。
